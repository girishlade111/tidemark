## Reference Findings
- Reference uses Geist Sans (`400`, `500`, `600`, `700`, `900`) and Lucide outline icons (`1.6px` stroke).
- Reference footer clocks (`London 09:00`, `New York 09:00`) are static opening-hours indicators (`Mon to Fri, 9 to 6`), preserved accurately without mislabeling as live clocks.
- Reference `Home` pricing section includes the 3-tier comparison table directly below the pricing cards.
- Reference `Blog` page concludes with the dark navy `Get the Monthly Tide.` newsletter block rather than the `Let's go higher.` cloud CTA.
